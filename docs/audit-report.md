# CloudScale Repository Audit

**Baseline:** 2026-11-23, `master` at `d240e2e`. The working tree contained a user edit setting `JWT_ISSUER=cloudscale-authf`; that value is preserved.  
**Final pass:** 2026-11-24 on the same `master` checkout. Work remains uncommitted.

## Executive summary

The original skeleton gaps have been filled within the existing six-service architecture: Auth/JWT, Gateway routing and correlation IDs, per-service tenant/role enforcement, transactional outboxes, idempotent Audit ingestion, deterministic Rollout behavior, and an API-backed Angular management client. Compose now passes service DNS and shared local credentials, publishes host ports only on loopback, and proxies browser `/api` calls through Gateway. README and architecture docs now describe the implementation rather than the old phase plan.

The read-only whole-working-tree review found no Critical issues. Important findings were addressed with regression tests. The known Rollout bean startup blocker was fixed with an explicit domain configuration and focused Spring context test.

The isolated local Compose stack built and started after registering the Rollout domain collaborators. Gateway, all services, Grafana, and Prometheus were healthy; all six Prometheus targets reported `up`. A local Gateway evaluation load benchmark completed with warm and cold scenarios. The full backend suite passed; 17 Testcontainers tests still skipped because Testcontainers could not initialize the Docker Desktop API reliably during Maven test execution. The integration-dependent requirements were separately exercised by Compose and the API benchmark where possible. See [`../performance/load-test/results/evaluation-local-20261124.md`](../performance/load-test/results/evaluation-local-20261124.md) and [`metrics-report.md`](metrics-report.md) for exact results and limits.

## Historical baseline

The baseline audit found missing Auth/Gateway/Tenant authorization, non-durable Kafka publishing, empty Audit/Rollout services, a static Angular shell, absent Maven Wrapper/CI, Docker healthchecks using unavailable tools, unsafe default credentials, and stale phase documentation. Those implementation gaps were addressed; remaining limitations are listed in the metrics report.
